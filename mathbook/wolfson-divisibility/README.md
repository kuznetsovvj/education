# Решения задач по математике (задачник Вольфсона и олимпиады)

В этом репозитории собраны мои решения задач из книги Георгия Вольфсона «Делимость с человеческим лицом» (издательство МЦНМО, Москва, 2021 год).

## 📁 Структура репозитория

Все задачи сгруппированы по темам (беседам) и разделам. Для каждой задачи приведено полное условие и подробное решение, оформленное в LaTeX.

- **Беседа 1:** Примеры и контрпримеры.
- **Беседа 2:** Свойства делимости
- **Беседа 3:** Простые и составные числа. Делители числа.
- **Беседа 4:** Десятичная запись числа.
- **Беседа 5:** Признаки делимости.
- **Беседа 6:** Уравнения в целых числах.
- **Беседа 7:** Остатки.
- **Задачник**
- **Задачи из экзаменов и олимпиад**
- **Задача 19 на профильном ЕГЭ по математике**

## 🛠 Инструменты

Все решения оформлены в формате **LaTeX** для удобства чтения и компиляции в PDF. 
Для компиляции используется стандартный набор пакетов `amsmath`, `amssymb`, `geometry` и поддержка русского языка (`babel`).
